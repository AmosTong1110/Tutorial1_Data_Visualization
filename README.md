# Power Australia

Power Australia is a simple educational website designed to help people understand household energy use, especially when comparing appliances and televisions. The project presents a clear, user-friendly explanation of why appliance efficiency matters and how small choices can influence electricity bills and energy consumption in Australian homes.

## Project Overview

This website is built as a three-page static web project using HTML, CSS, and JavaScript. It introduces the idea of energy awareness through a clean homepage, a television-focused information page, and an About Us page. The main goal is to make energy labels, appliance efficiency, and household electricity use easier to understand for everyday users.

## Website Content

The homepage explains key concepts such as:

- understanding energy labels
- comparing wattage and running time
- considering seasonal usage patterns
- how household habits affect annual electricity consumption

The Television page explores the relationship between screen size, technology, and power use. It includes visualisations such as bar charts and scatter plots to show how larger TVs typically consume more power, while factors like technology and energy rating can influence efficiency. These charts make the data story more accessible and help users understand how to compare models before purchasing.

## GenAI Use

This project also demonstrates the use of Generative AI in website development. GenAI was used to support the creation of the project structure, generate starter code, improve website copy, and help shape the data storytelling content. It assisted with drafting clear explanations, summarising design ideas, and refining the tone of the website so it feels informative and approachable.

Although GenAI contributed to the code and written content, the final project was reviewed and adapted to match the project’s purpose and educational goals. This reflects a realistic use of AI in digital design and data communication: it accelerates the early stages of development while human judgement remains important for accuracy, quality, and user value.

## Files Included

- index.html – landing page
- televisions.html – TV energy insights and charts
- about_us.html – project background and credits
- style.css – shared design styling
- script.js – page behaviour and navigation support
- Picture/ – visual assets and chart images

## How to View the Website

Open the project folder and launch index.html in a browser. For a smoother experience, you can also use a local development server such as Live Server in VS Code.

This project demonstrates how a small website can combine design, educational content, and data visualisation to communicate real-world ideas in a simple and engaging way.
